# Portfolio

A minimal, theme‑aware personal portfolio showcasing selected projects, clean UI design, and a consistent visual identity.

## Overview

This portfolio highlights my work as a React developer, focusing on modern UI, responsive layouts, and polished presentation.  
Each project is presented with a concise description, live demo link, and GitHub source.

## Features

- Clean, minimal UI with light/dark theme
- Responsive design for all devices
- Smooth transitions and consistent visual style
- Project cards with live previews and source links

## Tech Stack

- React
- MUI
- Vite
- JavaScript
- GitHub Pages
